# Data Dictionary

## Table: `clean_labor_force`

The primary analysis-ready table. All charts, models, and the AI assistant query this table.

| Column | Type | Description |
|---|---|---|
| `id` | SERIAL (integer) | Auto-generated primary key, unique per row |
| `country_name` | TEXT | Full country name, e.g. "Rwanda" |
| `country_iso3` | TEXT | 3-letter ISO country code, e.g. "RWA". Used for map geocoding in Tableau. |
| `year` | INTEGER | Year of observation, ranges from 1990 to 2025 |
| `labor_force_participation_rate` | NUMERIC(6,3) | Percentage (0-100) of the population aged 15+ that is part of the labor force (employed or actively seeking work), for that country and year. Source: World Bank indicator `SL.TLF.CACT.ZS` (modeled ILO estimate). |
| `loaded_at` | TIMESTAMP | When this row was last inserted or updated by the pipeline |

**Constraints**: `UNIQUE (country_iso3, year)` — ensures the load step never creates duplicate rows for the same country/year, even if run multiple times.

---

## Table: `raw_labor_force`

The raw audit trail — data exactly as received from the World Bank API, before any cleaning.

| Column | Type | Description |
|---|---|---|
| `id` | SERIAL | Primary key |
| `indicator_id` | TEXT | World Bank indicator code, e.g. "SL.TLF.CACT.ZS" |
| `indicator_name` | TEXT | Full indicator name as returned by the API |
| `country_id` | TEXT | World Bank's short country/region ID (2-letter, may be an aggregate) |
| `country_name` | TEXT | Country or aggregate name as returned by the API |
| `country_iso3` | TEXT | 3-letter ISO code as returned by the API (may be an aggregate code like "AFE") |
| `year` | TEXT | Year, kept as text at this raw stage (not yet validated/cast) |
| `value` | TEXT | The indicator value, kept as text (may be null/empty at this stage) |
| `unit` | TEXT | Unit field from the API (typically empty for this indicator) |
| `obs_status` | TEXT | Observation status flag from the API (typically empty) |
| `decimal_places` | TEXT | Decimal precision metadata from the API |
| `loaded_at` | TIMESTAMP | When this row was last inserted or updated |

## File: `data/clean/ml_predictions.csv`

Generated by `notebooks/02_ml.ipynb`. Contains the Random Forest and Linear Regression model's predictions on the held-out test set (years 2021-2025), used for the "predicted vs. actual" chart in Tableau.

| Column | Description |
|---|---|
| `country_name` | Country name |
| `country_iso3` | 3-letter ISO code |
| `year` | Year of the prediction (2021-2025) |
| `actual_rate` | The real, observed labor force participation rate |
| `predicted_rate` | Random Forest model's predicted rate |
| `linear_regression_predicted` | Linear Regression model's predicted rate |
